# Sample estates

Test and demonstration material for FALCON's discovery engine. **Everything here
is synthetic.** The certificates, keys, keystores, configuration and code were
generated by [`tools/build_fixtures.py`](tools/build_fixtures.py) for this
project. They protect nothing, belong to no real organisation, and use reserved
example domains.

| Path | What it exercises |
|---|---|
| `estates/payments-platform/` | A payments monorepo containing: code in Java, Go, Python, TypeScript and C; nginx TLS, SSH and IPsec configuration; Terraform KMS keys and HSMs; a cert-manager certificate; a CA chain and a legacy RSA-1024 certificate; a key (`deploy/keys/service.key`, generated for testing); SSH authorised keys; a JWKS; dependency manifests; a Spring Boot jar; and an ELF library with a statically linked OpenSSL |
| `estates/identity-service/` | An identity service containing: a Go key service; a Java signer using ML-DSA; nginx TLS configuration; and a P-384 CA chain |
| `images/payments-api-3.8.1.tar` | A minimal `docker save` image with layers and whiteouts |

`falcon serve --demo` scans these to populate the demonstration, and the server
tests use them.
